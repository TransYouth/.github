# [跨青年教育中心](https://transyouth.xyz)
跨青年教育中心（Trans Youth Education Center，以下简称 跨青年）成立于 2017 年的春天，是一家在中国大陆开展跨性别社群教育、文化建设及公众教育活动的非营利性公益机构。

我们致力于为跨性别青年及其社群提供专业的教育资源和支持，促进社会理解与接纳，并推动性别多样性文化的建设。

我们的愿景是：中国跨性别者能够在社会中被理解、支持和尊重，享有平等机会与尊严。

我们的使命是：跨青年教育中心致力于教育跨性别社群，实现跨性别者的自我认同；也致力于教育公众，提升跨性别者的能见度和接纳度，创造一个友善多元的社会环境。
